# HGLM resources
The repository contains lots of useful stuff for those interested in the hglm package, the book "Data Analysis Using Hierarchical Generalized Linear Models with R", and hierarchical generalized linear models in general.

On CRAN you find excellent documentation on the hglm package and links to recorded tutorials on YouTube (see http://www.youtube.com/playlist?list=PLn1OmZECD-n15vnYzvJDy5GxjNpVV5Jr8).
